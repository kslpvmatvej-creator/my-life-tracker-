# M-Protocol

Личный трекер дисциплины, зала и целей. React + Vite + Tailwind + Supabase (опционально).

## Запуск локально
```
npm install
npm run dev
```

## Медиа
Положи в папку `public/`:
- `m3.jpg` — фото BMW M3
- `m3-edit.mp4` — видео-эдит 16:9

## Деплой на GitHub Pages
1. Создай репозиторий, залей все файлы (без `node_modules`).
2. Settings -> Pages -> Source: **GitHub Actions**.
3. `git push` в ветку `main` — сборка и деплой пойдут сами (вкладка Actions).
4. Сайт будет по адресу `https://<ник>.github.io/<репозиторий>/`.

Vercel: Import Project -> Framework Vite, остальное по умолчанию.

## Синхронизация
1. В Supabase открой SQL Editor, выполни `supabase.sql` (создаёт только новую таблицу `tracker_state`).
2. В приложении: Система -> Облачная синхронизация -> вставь Project URL и anon key -> Сохранить.
3. Повтори один раз на втором устройстве.

Ключи лучше вводить в приложении (хранятся только в браузере), а не через `VITE_*` секреты: в собранный сайт они попадают открытым текстом.
